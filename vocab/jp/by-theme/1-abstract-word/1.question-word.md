## 1. The foundation: か

Japanese has no word-order change for questions. You take a normal sentence and add **か**. Question words stay where the answer would go.

- これは本です。→ これは本ですか。(Is this a book?)
- Casual: drop か and raise your pitch, or use の: 行く？ / 行くの？

## 2. The core question words

Your 5W1H maps like this, but it is missing some words Japanese needs daily.

|English|Japanese|Notes|
|---|---|---|
|What|何 (nani/nan)|_nan_ before だ/です/の/counters/t,d,n sounds|
|Who|誰 (dare)|Polite: どなた|
|When|いつ||
|Where|どこ|Polite: どちら|
|Why|どうして / なぜ|なんで is casual|
|How|どう / どうやって|どうやって = by what method|
|**Which**|どれ / どの / どちら|Not in 5W1H, but essential|
|**How much (price)**|いくら||
|**How many**|いくつ / 何+counter|何人, 何個, 何時, 何歳|
|**What kind**|どんな||
|**How long/far/much**|どのくらい / どれくらい||

So 5W1H is a good start, but you need roughly 5 more. "Which" and "how much/many" come up constantly.

## 3. Combinations with particles

This is where most of the power is. Question word + particle:

|Pattern|Meaning|Example|
|---|---|---|
|誰が|who (subject)|誰が来ましたか。|
|誰の|whose|これは誰のですか。|
|誰と|with whom|誰と行きますか。|
|何を|what (object)|何を食べますか。|
|何で|by what/with what|何で行きますか。(by what transport)|
|どこで|where (action)|どこで買いましたか。|
|どこに/へ|to where|どこに行きますか。|
|どこから / どこまで|from/to where||
|いつから / いつまで|since/until when||
|いつごろ|around when||
|何時 / 何曜日 / 何月|what time/day/month||
|どのくらい|how long/much|どのくらいかかりますか。|

Watch out: **何で** can mean "by what means" (なんで来た？) or casual "why" (なんで来た？). Context decides.

## 4. Same words, not questions

Add も/か/でも and the word stops being a question:

- 何か = something, どこか = somewhere, 誰か = someone
- 何も + negative = nothing, 誰も + negative = nobody
- 何でも = anything, 誰でも = anyone

## 5. Patterns beyond question words

|Pattern|Use|Example|
|---|---|---|
|～ですか/ますか|Standard yes/no|行きますか。|
|～でしょうか|Softer, more polite|駅はどこでしょうか。|
|～んですか|Asking for the reason/explanation|どうしたんですか。|
|～ませんか|Invitation|一緒に行きませんか。|
|～ましょうか|Offer|手伝いましょうか。|
|～てもいいですか|Permission|入ってもいいですか。|
|～てくれませんか / ～ていただけますか|Request|教えていただけますか。|
|～たらいいですか / ～ばいいですか|"What should I do?"|どうしたらいいですか。|
|～ね / ～よね / ～でしょう|Confirming|明日だよね？|
|～じゃない？|"Isn't it?"|これ、おかしくない？|
|AですかBですか|Either/or|コーヒーですか、紅茶ですか。|
|～かどうか|Embedded "whether"|行くかどうか分かりません。|
|～って？ / ～ってなに？|Casual "what's X?" / "you said X?"|「侘び寂び」ってなに？|
|～とは|"What is X (as a concept)?"|幸せとは何ですか。|
|One word + rising pitch|Casual reaction|本当？ / え？ / 嘘？|

## 6. Things worth knowing

- **んですか vs ですか**: ですか is neutral. んですか signals you noticed something and want an explanation. 「泣いているんですか」 is "are you crying (what's going on)?", while 「泣いていますか」 is a plain check.
- **Politeness ladder** for the same question: どこ？ → どこですか？ → どちらですか？ → どちらでしょうか？
- **Question words are not fronted.** Unlike English, 何を食べますか keeps 何を in the object slot. Just replace the answer with the question word.
- **Embedded questions** need no special grammar: 何を食べたか覚えていません (I don't remember what I ate).

## Priority order for learning

1. か + the 5W1H words
2. どれ/どの, いくら, いくつ, 何+counter, どんな
3. Particle combinations (誰と, どこで, いつから…)
4. んですか, ませんか, ましょうか, てもいいですか
5. ね/よね confirmation and casual rising intonation
