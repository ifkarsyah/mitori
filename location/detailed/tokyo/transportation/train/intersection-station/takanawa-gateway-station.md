# Takanawa Gateway

Opened in 2020, the newest station on the loop.

## Literal Meaning

高輪ゲートウェイ: "Takanawa gateway"
- 高輪 (たかなわ): 'high ring', an old district name
- ゲートウェイ (getowei): gateway (English loanword)
