# Abiko

Written in hiragana on Midosuji Line signage; the district's formal kanji name is 我孫子 (Abiko).

## Literal Meaning

あびこ: "written in hiragana; kanji form means 'grandchild'"
- 我孫子 (あびこ): the underlying kanji form: 我=I/we, 孫=grandchild, 子=child
