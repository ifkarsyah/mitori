# Potential Verbs

Say that someone "can" or "has the ability to" do something, or that something is "possible."

## Formation
| Type | Rule | Example |
|---|---|---|
| ru-verbs | drop る, add られる | <ruby>見<rt>み</rt></ruby>る → 見られる |
| u-verbs | drop final -u, add -eる | <ruby>行<rt>い</rt></ruby>く → 行ける、<ruby>話<rt>はな</rt></ruby>す → 話せる、<ruby>買<rt>か</rt></ruby>う → 買える、<ruby>泳<rt>およ</rt></ruby>ぐ → 泳げる、<ruby>待<rt>ま</rt></ruby>つ → 待てる、<ruby>読<rt>よ</rt></ruby>む → 読める、<ruby>死<rt>し</rt></ruby>ぬ → 死ねる、<ruby>遊<rt>あそ</rt></ruby>ぶ → 遊べる、<ruby>取<rt>と</rt></ruby>る → 取れる |
| irregular | | くる → こられる、する → できる |

Potential forms of ru-verbs (見られる) run noticeably longer than u-verbs' (取れる — which happen to end in hiragana る, coincidentally the same shape as a ru-verb dictionary form).

## Casual "ra-less" alternative for ru-verbs
A shorter potential form exists for ru-verbs and くる, built with -れる instead of -られる: <ruby>出<rt>で</rt></ruby>られる→出れる、見られる→見れる、こられる→これる. Increasingly common, especially among young speakers, but considered slightly substandard.

## Conjugation
Potential verbs themselves conjugate as regular ru-verbs.

<ruby>私<rt>わたし</rt></ruby>は<ruby>日本語<rt>にほんご</rt></ruby>が話せます。
I can speak Japanese.

私は<ruby>泳<rt>およ</rt></ruby>げないんです。
(The truth is) I cannot swim.

<ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>ったので、<ruby>海<rt>うみ</rt></ruby>に<ruby>行<rt>い</rt></ruby>けませんでした。
We could not go to the beach, because it rained.

| | short forms | | long forms | |
|---|---|---|---|---|
| | affirmative | negative | affirmative | negative |
| present | 見られる | 見られない | 見られます | 見られません |
| past | 見られた | 見られなかった | 見られました | 見られませんでした |
| te-form | 見られて | | | |

## Particles with potential verbs
を-taking verbs may keep を or switch to が once made potential; できる (potential of する) almost always takes が; every other particle stays unchanged.

<ruby>漢字<rt>かんじ</rt></ruby>を<ruby>読<rt>よ</rt></ruby>む　→　漢字が読める or 漢字を読める
<ruby>仕事<rt>しごと</rt></ruby>をする　→　仕事ができる （仕事をできる is considered substandard）
<ruby>山<rt>やま</rt></ruby>に<ruby>登<rt>のぼ</rt></ruby>る　→　山に登れる （no particle change）

## Notes
An alternative, more written/formal way to express "can do": dictionary form ＋ ことができる (negative: ことができない).
メアリーさんはギターを<ruby>弾<rt>ひ</rt></ruby>くことができます。（compare: ギターが弾けます）
このアパートでは<ruby>犬<rt>いぬ</rt></ruby>や<ruby>猫<rt>ねこ</rt></ruby>を<ruby>飼<rt>か</rt></ruby>うことができません。（compare: 犬や猫が飼えません）
