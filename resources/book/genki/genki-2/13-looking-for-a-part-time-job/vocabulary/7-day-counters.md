# Numbers — counting days

Largely irregular native-Japanese readings, distinct from the 〜<ruby>日<rt>にち</rt></ruby>pattern used for calendar dates ([[4-time-and-calendar]]):

| Days | Japanese |
|---|---|
| 1 | <ruby>一日<rt>いちにち</rt></ruby> |
| 2 | <ruby>二日<rt>ふつか</rt></ruby> |
| 3 | <ruby>三日<rt>みっか</rt></ruby> |
| 4 | <ruby>四日<rt>よっか</rt></ruby> |
| 5 | <ruby>五日<rt>いつか</rt></ruby> |
| 6 | <ruby>六日<rt>むいか</rt></ruby> |
| 7 | <ruby>七日<rt>なのか</rt></ruby> |
| 8 | <ruby>八日<rt>ようか</rt></ruby> |
| 9 | <ruby>九日<rt>ここのか</rt></ruby> |
| 10 | <ruby>十日<rt>とおか</rt></ruby> |

<ruby>一週間<rt>いっしゅうかん</rt></ruby>に<ruby>三日<rt>みっか</rt></ruby><ruby>働<rt>はたら</rt></ruby>いています ("I work three days a week") from the dialogue uses this same series — see [[6-一週間に三回]].
