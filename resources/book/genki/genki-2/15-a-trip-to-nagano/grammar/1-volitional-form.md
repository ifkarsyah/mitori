# Volitional Form

A less formal, casual equivalent of ましょう — suggesting a plan to a close friend, for example.

## Formation
| Type | Rule | Example |
|---|---|---|
| ru-verbs | drop る, add よう | <ruby>食<rt>た</rt></ruby>べる → 食べよう |
| u-verbs | drop final -u, add -おう | <ruby>行<rt>い</rt></ruby>く → 行こう、<ruby>話<rt>はな</rt></ruby>す → 話そう、<ruby>買<rt>か</rt></ruby>う → 買おう、<ruby>待<rt>ま</rt></ruby>つ → 待とう、<ruby>泳<rt>およ</rt></ruby>ぐ → 泳ごう、<ruby>読<rt>よ</rt></ruby>む → 読もう、<ruby>死<rt>し</rt></ruby>ぬ → 死のう、<ruby>遊<rt>あそ</rt></ruby>ぶ → 遊ぼう、<ruby>取<rt>と</rt></ruby>る → 取ろう |
| irregular | | くる → こよう、する → しよう |

<ruby>明日<rt>あした</rt></ruby>は<ruby>授業<rt>じゅぎょう</rt></ruby>がないから、<ruby>今晩<rt>こんばん</rt></ruby>、どこかに食べに<ruby>行<rt>い</rt></ruby>こう。
We don't have any classes tomorrow. Let's go some place for dinner tonight.

<ruby>結婚<rt>けっこん</rt></ruby>しようよ。
Hey, let's get married!

## Volitional ＋ か — offering, asking for an opinion
<ruby>手伝<rt>てつだ</rt></ruby>おうか。

<ruby>友<rt>とも</rt></ruby>だちがおもしろいと<ruby>言<rt>い</rt></ruby>っていたから、この<ruby>映画<rt>えいが</rt></ruby>を<ruby>見<rt>み</rt></ruby>ようか。
Shall we see this film? My friends say it is good.

<ruby>今度<rt>こんど</rt></ruby>、いつ<ruby>会<rt>あ</rt></ruby>おうか。
