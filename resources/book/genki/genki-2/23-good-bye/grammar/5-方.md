# 〜<ruby>方<rt>かた</rt></ruby>

The noun-forming suffix 方 follows a verb **stem** and means "the way in which the action is performed" or "how to do..."

<ruby>泳<rt>およ</rt></ruby>ぐ → 泳ぎ方　how to swim
<ruby>考<rt>かんが</rt></ruby>える → 考え方　the way people think

Nouns marked with other particles when paired with the verb take の before 〜方:

<ruby>漢字<rt>かんじ</rt></ruby>を<ruby>読<rt>よ</rt></ruby>む → 漢字の読み方　how to read the kanji; pronunciation
はしを<ruby>使<rt>つか</rt></ruby>う → はしの使い方　how to use chopsticks
<ruby>空港<rt>くうこう</rt></ruby>に行く → 空港の行き方　how to go to the airport (also: 空港への行き方, since に can combine with への for a goal-of-movement)
お<ruby>風呂<rt>ふろ</rt></ruby>に<ruby>入<rt>はい</rt></ruby>る → お風呂の入り方　how to take a bath

## With する compound verbs
<ruby>日本語<rt>にほんご</rt></ruby>を<ruby>勉強<rt>べんきょう</rt></ruby>する → 日本語の勉強のし方
ホテルを<ruby>予約<rt>よやく</rt></ruby>する → ホテルの予約のし方

## 〜方 is a noun — takes は／を like any noun
たけしさんのスパゲッティの<ruby>食<rt>た</rt></ruby>べ方はおもしろいです。
The way in which Takeshi eats spaghetti is interesting.

すみません。この漢字の<ruby>書<rt>か</rt></ruby>き方を<ruby>教<rt>おし</rt></ruby>えていただけませんか。
Excuse me, can you tell me how to write this kanji?
