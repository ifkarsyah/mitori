# Verbs

## U-verbs
| Japanese                  | Meaning                              |
| ------------------------- | ------------------------------------ |
| ある                        | there is...（place に thing が）         |
| <ruby>会<rt>あ</rt></ruby>う | to meet; to see (a person)（person に） |
| <ruby>買<rt>か</rt></ruby>う | to buy（〜を）                           |
| <ruby>書<rt>か</rt></ruby>く | to write（person に thing を）           |
| <ruby>撮<rt>と</rt></ruby>る | to take (a picture)（〜を）              |
| <ruby>待<rt>ま</rt></ruby>つ | to wait（〜を）                          |
| わかる                       | to understand（〜が）                    |

## Ru-verb
| Japanese | Meaning |
|---|---|
| いる | (a person) is in...; stays at...（place に person が） |

See [[1-xがあります-います]] for the ある／いる distinction this lesson centers on.
