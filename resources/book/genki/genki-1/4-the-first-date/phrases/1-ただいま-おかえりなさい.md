# ただいま／おかえりなさい

The fixed exchange for returning home, paired with [[1-いってきます-いってらっしゃい]] for leaving.

メアリー：ただいま。
Mary: I'm home.

お<ruby>父<rt>とう</rt></ruby>さん：おかえりなさい。<ruby>映画<rt>えいが</rt></ruby>はどうでしたか。
Host father: Welcome home. How was the movie?
