# U-verbs

| Japanese | Meaning |
|---|---|
| <ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>る | it rains |
| <ruby>洗<rt>あら</rt></ruby>う | to wash（〜を） |
| <ruby>言<rt>い</rt></ruby>う | to say |
| いる | to need（〜が） |
| <ruby>遅<rt>おそ</rt></ruby>くなる | to be late |
| <ruby>思<rt>おも</rt></ruby>う | to think |
| <ruby>切<rt>き</rt></ruby>る | to cut（〜を） |
| <ruby>作<rt>つく</rt></ruby>る | to make（〜を） |
| <ruby>持<rt>も</rt></ruby>っていく | to take (a thing)（〜を） |

いる ("to need") here is spelled the same in kana as the ru-verb いる ("to be, for people") from [[5-verbs]] but is a different word — an u-verb, conjugating いらない not ×いない.
