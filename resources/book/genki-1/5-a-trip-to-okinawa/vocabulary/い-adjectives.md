# い-adjectives

| Japanese | Meaning |
|---|---|
| 新（あたら）しい | new |
| 暑（あつ）い | hot (weather) |
| 熱（あつ）い | hot (thing) |
| 忙（いそが）しい | busy (people/days) — see [[../phrases/忙しい-にぎやか]] |
| 大（おお）きい | large |
| 面白（おもしろ）い | interesting; funny |
| かっこいい | good-looking (conjugates like いい) |
| 怖（こわ）い | frightening |
| 寒（さむ）い | cold (weather — not used for things) |
| 楽（たの）しい | fun |
| 小（ちい）さい | small |
| つまらない | boring |
| 古（ふる）い | old (thing — not used for people) |
| 難（むずか）しい | difficult |
| やさしい | easy (problem); kind (person) |
| 安（やす）い | inexpensive; cheap (thing) |

See [[../grammar/adjectives]] for conjugation, including いい's irregular pattern.
