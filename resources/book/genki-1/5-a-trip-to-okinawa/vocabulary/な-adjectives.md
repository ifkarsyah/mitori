# な-adjectives

| Japanese | Meaning |
|---|---|
| きらい（な） | disgusted with; to dislike（〜が） |
| きれい（な） | beautiful; clean |
| 元気（げんき）（な） | healthy; energetic |
| 静（しず）か（な） | quiet |
| 好（す）き（な） | fond of; to like（〜が） |
| 大嫌（だいきら）い（な） | to hate（〜が） |
| 大好（だいす）き（な） | very fond of; to love（〜が） |
| にぎやか（な） | lively — see [[../phrases/忙しい-にぎやか]] |
| 暇（ひま）（な） | not busy; to have a lot of free time |

See [[../grammar/好き-きらい]] for the grammar behind 好き／きらい specifically, and [[../grammar/adjectives]] for な-adjective conjugation generally.
