# U-verbs

| Japanese | Meaning |
|---|---|
| 雨（あめ）が降（ふ）る | it rains |
| 洗（あら）う | to wash（〜を） |
| 言（い）う | to say |
| いる | to need（〜が） |
| 遅（おそ）くなる | to be late |
| 思（おも）う | to think |
| 切（き）る | to cut（〜を） |
| 作（つく）る | to make（〜を） |
| 持（も）っていく | to take (a thing)（〜を） |

いる ("to need") here is spelled the same in kana as the ru-verb いる ("to be, for people") from [[../../4-the-first-date/vocabulary/verbs]] but is a different word — an u-verb, conjugating いらない not ×いない.
