# Foods & Drinks

| Japanese | Meaning |
|---|---|
| アイスクリーム | ice cream |
| 朝（あさ）ご飯（はん） | breakfast |
| お酒（さけ） | sake; alcohol |
| お茶（ちゃ） | green tea |
| コーヒー | coffee |
| 晩（ばん）ご飯（はん） | dinner |
| ハンバーガー | hamburger |
| 昼（ひる）ご飯（はん） | lunch |
| 水（みず） | water |

朝ご飯／昼ご飯／晩ご飯 share the ご飯 (meal) root — memorize them as a set with [[time-words]]'s 朝／昼／晩.
