# Time Words

| Japanese | Meaning |
|---|---|
| 朝（あさ） | morning |
| 明日（あした） | tomorrow |
| いつ | when |
| 今日（きょう） | today |
| 〜ごろ | at about... |
| 今晩（こんばん） | tonight |
| 週末（しゅうまつ） | weekend |
| 土曜日（どようび） | Saturday |
| 日曜日（にちようび） | Sunday |
| 毎日（まいにち） | every day |
| 毎晩（まいばん） | every night |

See [[../grammar/time-reference]] for exactly which of these take に and which don't — it's not a uniform rule across this list.
