# Entertainment & Sports

| Japanese | Meaning |
|---|---|
| 映画（えいが） | movie |
| 音楽（おんがく） | music |
| 雑誌（ざっし） | magazine |
| スポーツ | sports |
| デート | date (romantic, not calendar) |
| テニス | tennis |
| テレビ | TV |

This is the first lesson where the vocabulary table shows kanji — kanji itself isn't taught until 読み書き編 Lesson 5, so students aren't expected to write these yet, only recognize them with the furigana shown.
