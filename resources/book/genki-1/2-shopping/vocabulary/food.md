# Food

| Japanese | Meaning |
|---|---|
| おいしい | delicious |
| さかな | fish |
| とんかつ | pork cutlet |
| にく | meat |
| メニュー | menu |
| やさい | vegetable |

## Notes
おいしい appears in the dialogue as おいしいですよ ("It's delicious!") — an adjective, not a noun, so it can't be negated with [[../grammar/noun-じゃないです]] (see the note there).
