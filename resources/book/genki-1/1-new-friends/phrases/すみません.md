# すみません

Opens the lesson's dialogue — used to get a stranger's attention before asking something, functioning like English "excuse me":

すみません。いま　なんじですか。
Excuse me. What time is it now?

Also doubles as a light apology ("sorry" / "excuse me" for a minor inconvenience) in other contexts, though this lesson only uses the attention-getting sense.
