# Family (Additional Vocabulary, p. 41)

| Japanese                     | Meaning         |
| ---------------------------- | --------------- |
| お<ruby>母<rt>かあ</rt></ruby>さん | mother          |
| お<ruby>父<rt>とう</rt></ruby>さん | father          |
| お<ruby>姉<rt>ねえ</rt></ruby>さん | older sister    |
| お<ruby>兄<rt>にい</rt></ruby>さん | older brother   |
| <ruby>妹<rt>いもうと</rt></ruby>  | younger sister  |
| <ruby>弟<rt>おとうと</rt></ruby>  | younger brother |

## Notes
- These are the terms used for describing *someone else's* family members (e.g. Mary's host family, pp. 53–54). Genki flags that referring to one's *own* family uses a different, plainer set of words — that distinction gets its own Culture Note in [[../../7-family-picture|Lesson 7]] (<ruby>家族<rt>かぞく</rt></ruby>の<ruby>呼<rt>よ</rt></ruby>び<ruby>方<rt>かた</rt></ruby>, Kinship Terms), not covered here.
- Used with [[../grammar/1-x-は-y-です]] in the host-family drill: お<ruby>父<rt>とう</rt></ruby>さんは　<ruby>会社員<rt>かいしゃいん</rt></ruby>です。("Father is an office worker.")
