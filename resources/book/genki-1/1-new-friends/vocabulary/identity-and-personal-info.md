# Identity & Personal Info

| Japanese | Meaning |
|---|---|
| わたし | I |
| なまえ | name |
| でんわ | telephone |
| ばんごう | number (see also [[time-and-numbers]] for でんわばんごう usage) |
| 〜さん | Mr./Ms. |
| なん／なに | what |

## Notes
- なん vs なに: なん is used immediately before です or before a counter (なんじ、なんさい); なに is used before a particle. See [[../grammar/question-sentences]].
- 〜さん attaches after a given or family name as a generic honorific title — never used to refer to yourself. See [[../phrases/self-introduction]] for how a name is introduced without さん (メアリー・ハートです, not メアリーさんです for oneself).
- でんわばんごう (telephone number) — asking for it: でんわばんごうは　なんですか。
