# Identity & Personal Info

| Japanese | Meaning |
|---|---|
| <ruby>私<rt>わたし</rt></ruby> | I |
| <ruby>名前<rt>なまえ</rt></ruby> | name |
| <ruby>電話<rt>でんわ</rt></ruby> | telephone |
| <ruby>番号<rt>ばんごう</rt></ruby> | number (see also [[1-time-and-numbers]] for <ruby>電話番号<rt>でんわばんごう</rt></ruby> usage) |
| 〜さん | Mr./Ms. |
| なん／なに | what |

## Notes
- なん vs なに: なん is used immediately before です or before a counter (<ruby>何時<rt>なんじ</rt></ruby>、<ruby>何歳<rt>なんさい</rt></ruby>); なに is used before a particle. See [[../grammar/2-question-sentences]].
- 〜さん attaches after a given or family name as a generic honorific title — never used to refer to yourself. See [[../phrases/7-self-introduction]] for how a name is introduced without さん (メアリー・ハートです, not メアリーさんです for oneself).
- <ruby>電話番号<rt>でんわばんごう</rt></ruby> (telephone number) — asking for it: <ruby>電話番号<rt>でんわばんごう</rt></ruby>は　<ruby>何<rt>なん</rt></ruby>ですか。
