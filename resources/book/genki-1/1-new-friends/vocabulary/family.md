# Family (Additional Vocabulary, p. 41)

| Japanese | Meaning |
|---|---|
| おかあさん | mother |
| おとうさん | father |
| おねえさん | older sister |
| おにいさん | older brother |
| いもうと | younger sister |
| おとうと | younger brother |

## Notes
- These are the terms used for describing *someone else's* family members (e.g. Mary's host family, pp. 53–54). Genki flags that referring to one's *own* family uses a different, plainer set of words — that distinction gets its own Culture Note in [[../../7-family-picture|Lesson 7]] (家族の呼び方（かぞくのよびかた）, Kinship Terms), not covered here.
- Used with [[../grammar/x-は-y-です]] in the host-family drill: おとうさんは　かいしゃいんです。("Father is an office worker.")
