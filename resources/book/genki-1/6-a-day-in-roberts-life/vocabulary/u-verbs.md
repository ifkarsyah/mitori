# U-verbs

| Japanese | Meaning |
|---|---|
| 遊（あそ）ぶ | to play; to spend time pleasantly |
| 急（いそ）ぐ | to hurry |
| お風呂（ふろ）に入（はい）る | to take a bath |
| 返（かえ）す | to return (a thing)（person に thing を） |
| 消（け）す | to turn off; to erase（〜を） |
| 死（し）ぬ | to die |
| 座（すわ）る | to sit down（seat に） |
| 立（た）つ | to stand up |
| たばこを吸（す）う | to smoke |
| 使（つか）う | to use（〜を） |
| 手伝（てつだ）う | to help（person/task を） |
| 入（はい）る | to enter（〜に） |
| 持（も）つ | to carry; to hold（〜を） |
| 休（やす）む | (1) to be absent (from...)（〜を） (2) to rest |

This lesson's verb set is chosen to exercise every [[../grammar/te-form]] subgroup — う／つ／る、む／ぶ／ぬ、く、ぐ、す — see the grammar note for the full conjugation breakdown.
