# In the Japanese Class（日本語（にほんご）のクラスで, Useful Expressions p. 265）

## Expressions
| Japanese | Meaning |
|---|---|
| どちらでもいいです。 | Both are fine. |
| 同（おな）じです。 | Same thing. |
| だいたい同じです。 | More or less the same. |
| ちょっと違（ちが）います。 | A little different. |
| 使（つか）えません。 | Can't use it. |
| だめです。 | No good. |
| 手（て）をあげてください。 | Raise your hand. |
| 読（よ）んできてください。 | Read it before coming to class. |
| 宿題（しゅくだい）を出（だ）してください。 | Hand in the homework. |
| 教科書（きょうかしょ）を閉（と）じてください。 | Close the textbook. |
| となりの人（ひと）に聞（き）いてください。 | Ask the person sitting next to you. |
| やめてください。 | Please stop. |
| 今日（きょう）はこれで終（お）わります。 | That's it for today. |
