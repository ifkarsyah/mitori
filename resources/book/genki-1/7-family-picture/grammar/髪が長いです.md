# メアリーさんは髪が長いです

To describe someone's physical attribute, Japanese far more naturally uses a **double-subject** construction than a possessive one.

トムさんの髪は長いです。 ("Tom's hair is long" — grammatical, but unnatural)
トムさんは髪が長いです。 ("Tom has long hair," lit. "As for Tom, hair is long" — the natural phrasing)

## The general pattern
A さんは　｛目／耳／手／足…｝が　｛大きい／小さい／かわいい…｝　です。
"Person A has a body part which is ..."

See [[../vocabulary/parts-of-the-body]] for the body-part word list this pattern draws on.

## Idiomatic collocations
背（せ）が高（たか）い — is tall
背が低（ひく）い — is short
頭（あたま）がいい — is bright/smart

These aren't literally "back is tall" or "head is good" in any compositional sense — they're fixed idioms built on the same X は Y が ＿＿ です frame.

## Notes
This same construction extends beyond physical description to anything with a "whole has a part with property" shape — it isn't a special-purpose "body" grammar point, just the most common context where it shows up at this level.
