# い-adjectives

| Japanese | Meaning |
|---|---|
| 頭（あたま）がいい | bright; smart; clever (conjugates like いい) |
| かわいい | cute |
| 背（せ）が高（たか）い | tall (stature) |
| 背が低（ひく）い | short (stature) |
| 長（なが）い | long |
| 速（はや）い | fast |
| 短（みじか）い | short (length) |

These physical-description adjectives are the vocabulary core of [[../grammar/髪が長いです]]'s X は Y が ＿＿ です pattern.
