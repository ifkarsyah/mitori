# ただいま／おかえりなさい

The fixed exchange for returning home, paired with [[../../3-making-a-date/phrases/いってきます-いってらっしゃい]] for leaving.

メアリー：ただいま。
Mary: I'm home.

お父（とう）さん：おかえりなさい。映画（えいが）はどうでしたか。
Host father: Welcome home. How was the movie?
