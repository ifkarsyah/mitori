# Location Words

| Japanese | Meaning |
|---|---|
| 右（みぎ） | right（〜の） |
| 左（ひだり） | left（〜の） |
| 前（まえ） | front（〜の） |
| 後（うし）ろ | back（〜の） |
| 中（なか） | inside（〜の） |
| 上（うえ） | on（〜の） |
| 下（した） | under（〜の） |
| 近（ちか）く | near; nearby（〜の） |
| 隣（となり） | next（〜の） |
| 間（あいだ） | between (A と B の) |

The full construction and usage caveats (となり vs よこ, X の前 vs X のむかい) are in [[../grammar/describing-where-things-are]].
