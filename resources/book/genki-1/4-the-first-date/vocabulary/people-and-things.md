# People & Things

| Japanese | Meaning |
|---|---|
| あなた | you |
| いす | chair |
| 犬（いぬ） | dog |
| お土産（みやげ） | souvenir |
| 子供（こども） | child |
| ご飯（はん） | rice; meal |
| 写真（しゃしん） | picture; photograph |
| 机（つくえ） | desk |
| 手紙（てがみ） | letter |
| 猫（ねこ） | cat |
| パン | bread |
| 人（ひと） | person |
| メール | e-mail |

Central to this lesson's あります／います drills ([[../grammar/xがあります-います]]) — 犬／猫／人 need います (animate), everything else needs あります.
