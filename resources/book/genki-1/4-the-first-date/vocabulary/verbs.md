# Verbs

## U-verbs
| Japanese | Meaning |
|---|---|
| 会（あ）う | to meet; to see (a person)（person に） |
| ある | there is...（place に thing が） |
| 買（か）う | to buy（〜を） |
| 書（か）く | to write（person に thing を） |
| 撮（と）る | to take (a picture)（〜を） |
| 待（ま）つ | to wait（〜を） |
| わかる | to understand（〜が） |

## Ru-verb
| Japanese | Meaning |
|---|---|
| いる | (a person) is in...; stays at...（place に person が） |

See [[../grammar/xがあります-います]] for the ある／いる distinction this lesson centers on.
