# U-verbs

| Japanese | Meaning |
|---|---|
| 歩（ある）く | to walk |
| 風邪（かぜ）をひく | to catch a cold |
| 興味（きょうみ）がある | to be interested (in...)（topic に） |
| なくす | to lose（〜を） |
| 熱（ねつ）がある | to have a fever |
| のどが渇（かわ）く | to become thirsty |

風邪をひく／熱がある／のどが渇く are this lesson's core symptom vocabulary, all built around this chapter's あの、もうすぐテニスの試合があるので、練習しなきゃいけないんですが……dialogue.
