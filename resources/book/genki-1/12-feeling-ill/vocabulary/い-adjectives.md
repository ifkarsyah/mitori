# い-adjectives

| Japanese | Meaning |
|---|---|
| 甘（あま）い | sweet |
| 痛（いた）い | hurt; painful |
| 多（おお）い | there are many... |
| 狭（せま）い | narrow; not spacious |
| 都合（つごう）が悪（わる）い | inconvenient; to have a scheduling conflict |
| 悪（わる）い | bad |

都合が悪い is this lesson's standard soft way to decline an invitation — see the Lesson 12 review dialogue: ちょっと都合が悪いんです。
