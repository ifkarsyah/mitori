# Giving Respectful Advice

The pattern "お＋verb stem＋ください" appears in public-address announcements and store-attendant speech.

切符（きっぷ）をお取（と）りください。
Please take a ticket. (< 取る)

説明（せつめい）をお読（よ）みください。
Please read the instruction. (< 読む)

## Command, not request
Although these sentences end in ください, treat them as (courteously phrased) **commands** rather than requests — the listener is being encouraged to act for their own good. So it's wrong to use this pattern to ask someone to do something *for you*:

×塩（しお）をお取りください。
(intended: "Please take the salt [and pass it to me]" — wrong)

Use instead: 塩を取っていただけませんか。 (see [[../../16-lost-and-found/grammar/ていただけませんか]])

## する compound verbs — ご instead of お
ご注意（ちゅうい）ください。
Please watch out. (< 注意する)

## With special honorific verbs
ご覧（らん）ください。
Please look. (< ご覧になる < 見る)

お召（め）し上（あ）がりください。
Please help yourself. (< 召し上がる < 食べる)

お休（やす）みください。
Please have a good rest. (< お休みになる < 寝る)
