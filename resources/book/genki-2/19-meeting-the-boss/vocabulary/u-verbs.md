# U-verbs

## Honorific
| Japanese | Meaning |
|---|---|
| いらっしゃる | honorific for いく、くる、and いる — see [[../grammar/honorific-verbs]] |
| おっしゃる | honorific for いう |
| くださる | honorific for くれる |
| なさる | honorific for する |
| ご覧（らん）になる | honorific for みる |
| お休（やす）みになる | honorific for ねる |
| 召（め）し上（あ）がる | honorific for たべる and のむ |
| 〜ていらっしゃる | honorific for 〜ている |

## Regular
| Japanese | Meaning |
|---|---|
| 送（おく）る | to walk/drive (someone)（person を place まで） |
| 怒（おこ）る | to get angry |
| 決（き）まる | to be decided（〜が） |
| 知（し）り合（あ）う | to get acquainted with（〜と） |
| 引（ひ）っ越（こ）す | to move (to another place to live)（〜に） |
| 呼（よ）ぶ | to call (one's name)（〜を） |
| 寄（よ）る | to stop by（〜に） |
