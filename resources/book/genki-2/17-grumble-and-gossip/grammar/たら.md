# 〜たら

One of several Japanese words expressing conditional ("if") dependence. "A たら B" means B is valid, contingent on A being fulfilled — B is realized if and when condition A is met.

日本（にほん）に行（い）ったら、着物（きもの）を買（か）います。
I will buy kimono if and when I go to Japan.

## Formation — た from the short-form past ending
| | affirmative | negative |
|---|---|---|
| verbs | 読（よ）んだら | 読まなかったら |
| い-adjectives | やさしかったら | やさしくなかったら |
| な-adjectives | 静（しず）かだったら | 静かじゃなかったら |
| noun＋です | 休（やす）みだったら | 休みじゃなかったら |

## A possible condition, with a following consequence
天気（てんき）がよかったら、散歩（さんぽ）に行きます。
We will go for a walk, if the weather is fine.

山下先生（やましたせんせい）に会（あ）ったら、そのことを聞（き）こうと思（おも）います。
I will ask about it, if I see Professor Yamashita.

日本人（にほんじん）だったら、この言葉（ことば）を知（し）っているでしょう。
If somebody is a Japanese person, then they will probably know this word.

宝（たから）くじに当（あ）たったら、アムネスティにお金（かね）を送（おく）ります。
I would send money to Amnesty International, if I should win the lottery.

## Notes on sequencing
"A たら B" can only describe B happening at the time A comes true, **or later** — never a B that precedes A. So a "B before next week's exam" reading is impossible:
×来週試験（らいしゅうしけん）があったら、今度の週末（しゅうまつ）は勉強したほうがいいですよ。
("It will be better for you to study this weekend, if you have an exam next week" — ungrammatical, since B/studying would need to precede A/the exam)

## A probable condition, arranging a future sequence
When the condition is very likely, たら can simply arrange two future events in temporal order — closer to "when" than "if":
今晩（こんばん）、うちに帰（かえ）ったら、電話（でんわ）します。
I will call you when I get home tonight.

宿題（しゅくだい）が終（お）わったら、遊（あそ）びに行きましょう。
Let's go out and have some fun once we are done with the homework.

The very same sentence can carry either an "if" or a "when" reading — the difference lies in how certain the real-world situation is, not in the sentence itself.

## A purely hypothetical, contrary-to-fact condition
私（わたし）が猫（ねこ）だったら、一日中（いちにちじゅう）寝（ね）ているでしょう。
If I were a cat, I would be asleep all day long.

お金があったら、車（くるま）を買うんですけど。
If I had money, I would buy a car.

## Notes
たら can only describe a condition that holds *naturally* between A and B — it cannot express "B even if A" (B holding in spite of A):
×あなたが結婚（けっこん）したかったら、私は結婚しません。
(intended: "I will not marry you even if you want to.")
