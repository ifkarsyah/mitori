# At the Barber/Beauty Salon（床屋（とこや）／美容院（びよういん）で, Useful Expressions p. 139）

## Expressions
| Japanese | Meaning |
|---|---|
| カット（パーマ）お願（ねが）いします。 | I would like to have a hair cut (permanent). |
| あまり短（みじか）くしないでください。 | Please don't make it too short. |
| そらないでください。 | Please don't shave. |
| 3センチぐらい切（き）ってください。 | Please cut off about 3 centimeters. |
| 後（うし）ろをそろえてください。 | Please cut the back all the same length. |
| 赤（あか）にそめてください。 | Please dye my hair red. |
| ボブ・マーリーみたいな髪形（かみがた）にしたいんですが。 | I want my hair to be like Bob Marley's. (showing the picture) |
