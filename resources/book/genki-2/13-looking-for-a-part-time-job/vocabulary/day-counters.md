# Numbers — counting days

Largely irregular native-Japanese readings, distinct from the 〜日（にち）pattern used for calendar dates ([[../../../genki-1/4-the-first-date/vocabulary/time-and-calendar]]):

| Days | Japanese |
|---|---|
| 1 | いちにち（一日） |
| 2 | ふつか（二日） |
| 3 | みっか（三日） |
| 4 | よっか（四日） |
| 5 | いつか（五日） |
| 6 | むいか（六日） |
| 7 | なのか（七日） |
| 8 | ようか（八日） |
| 9 | ここのか（九日） |
| 10 | とおか（十日） |

一週間（いっしゅうかん）に三日（みっか）働（はたら）いています ("I work three days a week") from the dialogue uses this same series — see [[../grammar/一週間に三回]].
