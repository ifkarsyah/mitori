# い-adjectives

| Japanese | Meaning |
|---|---|
| うれしい | glad |
| 悲（かな）しい | sad |
| 辛（から）い | hot and spicy; salty |
| 厳（きび）しい | strict |
| すごい | incredible; awesome |
| 近（ちか）い | close; near |

This lesson's [[../grammar/そうです-looks-like|そうです]] practice runs almost entirely on this list plus [[な-adjectives]] — うれしそう、悲しそう、厳しそう, etc.
