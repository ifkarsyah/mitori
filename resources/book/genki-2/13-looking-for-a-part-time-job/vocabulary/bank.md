# At the Bank（銀行（ぎんこう）で, Useful Expressions p. 49）

## Vocabulary
| Japanese | Meaning |
|---|---|
| 口座（こうざ） | account |
| 手数料（てすうりょう） | commission |
| キャッシュカード | bank card |
| 通帳（つうちょう） | passbook |
| 預金（よきん） | savings |
| 百円玉（ひゃくえんだま） | 100-yen coin |
| 金額（きんがく） | amount |
| 暗証番号（あんしょうばんごう） | personal identification number |

## Expressions
| Japanese | Meaning |
|---|---|
| 口座を開（ひら）きたいんですが。 | I would like to open an account. |
| 口座を閉（と）じたいんですが。 | I would like to close an account. |
| ドルを円（えん）にかえてください。 | Please change dollars into yen. |
| 口座にお金を振（ふ）り込（こ）みたいんですが。 | I would like to deposit money into the account. |
| 一万円札（いちまんえんさつ）を千円札（せんえんさつ）十枚（じゅうまい）に両替（りょうがえ）できますか。 | Can you change a 10,000-yen bill into ten 1,000-yen bills? |
| お金をおろします。 | I will withdraw money. |
