# Potential Verbs

Say that someone "can" or "has the ability to" do something, or that something is "possible."

## Formation
| Type | Rule | Example |
|---|---|---|
| ru-verbs | drop る, add られる | 見（み）る → 見られる |
| u-verbs | drop final -u, add -eる | 行（い）く → 行ける、話（はな）す → 話せる、買（か）う → 買える、泳（およ）ぐ → 泳げる、待（ま）つ → 待てる、読（よ）む → 読める、死（し）ぬ → 死ねる、遊（あそ）ぶ → 遊べる、取（と）る → 取れる |
| irregular | | くる → こられる、する → できる |

Potential forms of ru-verbs (見られる) run noticeably longer than u-verbs' (取れる — which happen to end in hiragana る, coincidentally the same shape as a ru-verb dictionary form).

## Casual "ra-less" alternative for ru-verbs
A shorter potential form exists for ru-verbs and くる, built with -れる instead of -られる: 出（で）られる→出れる、見られる→見れる、こられる→これる. Increasingly common, especially among young speakers, but considered slightly substandard.

## Conjugation
Potential verbs themselves conjugate as regular ru-verbs.

私（わたし）は日本語（にほんご）が話せます。
I can speak Japanese.

私は泳（およ）げないんです。
(The truth is) I cannot swim.

雨（あめ）が降（ふ）ったので、海（うみ）に行（い）けませんでした。
We could not go to the beach, because it rained.

| | short forms | | long forms | |
|---|---|---|---|---|
| | affirmative | negative | affirmative | negative |
| present | 見られる | 見られない | 見られます | 見られません |
| past | 見られた | 見られなかった | 見られました | 見られませんでした |
| te-form | 見られて | | | |

## Particles with potential verbs
を-taking verbs may keep を or switch to が once made potential; できる (potential of する) almost always takes が; every other particle stays unchanged.

漢字（かんじ）を読（よ）む　→　漢字が読める or 漢字を読める
仕事（しごと）をする　→　仕事ができる （仕事をできる is considered substandard）
山（やま）に登（のぼ）る　→　山に登れる （no particle change）

## Notes
An alternative, more written/formal way to express "can do": dictionary form ＋ ことができる (negative: ことができない).
メアリーさんはギターを弾（ひ）くことができます。（compare: ギターが弾けます）
このアパートでは犬（いぬ）や猫（ねこ）を飼（か）うことができません。（compare: 犬や猫が飼えません）
