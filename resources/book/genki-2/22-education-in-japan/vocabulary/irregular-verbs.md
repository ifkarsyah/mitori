# Irregular Verbs

| Japanese | Meaning |
|---|---|
| お願（ねが）いする | to pray for help（person に〜を） |
| 賛成（さんせい）する | to agree（〜に） |
| 失敗（しっぱい）する | to fail; to be unsuccessful |
| 徹夜（てつや）する | to stay up all night |
| 反対（はんたい）する | to oppose; to object to（〜に） |
| 翻訳（ほんやく）する | to translate（〜を） |
