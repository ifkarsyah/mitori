# Adverbs & Expressions

| Japanese | Meaning |
|---|---|
| こんなふう | like this |
| 自由（じゆう）に | freely |
| ずっと | for a long time; all the time |
| 絶対（ぜったい）に | definitely |
| そんなこと（は）ない | I don't think so. |
| 〜とか | ...for example |
| 何度（なんど）も | many times |
| もう少（すこ）し | a little more |
