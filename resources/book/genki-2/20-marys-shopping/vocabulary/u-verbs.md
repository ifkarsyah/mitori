# U-verbs

## Extra-modest / humble
| Japanese | Meaning |
|---|---|
| 致（いた）す | extra-modest expression for する |
| いただく | extra-modest expression for たべる and のむ；also the humble expression for もらう |
| うかがう（伺う） | to humbly visit; to humbly ask |
| おる | extra-modest expression for いる |
| ござる | extra-modest expression for ある |
| 〜ておる | extra-modest expression for 〜ている |
| でござる | extra-modest expression for です |
| 参（まい）る | extra-modest expression for いく and くる |
| 申（もう）す | extra-modest expression for いう |
