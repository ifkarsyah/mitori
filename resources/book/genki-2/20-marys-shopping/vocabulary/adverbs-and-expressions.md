# Adverbs & Expressions

| Japanese | Meaning |
|---|---|
| おや？ | Oh! |
| 〜階（かい） | ...th floor |
| かしこまりました | Certainly. |
| さあ | I am not sure,... |
| 失礼（しつれい）しました | I'm very sorry. |
| 少々（しょうしょう） | a few seconds |
| それでは | if that is the case,... |
| できれば | if possible |
| まことに（誠に） | really (very polite) |
| また | again |
| 〜みたいなX | X such as... |
| 申（もう）し訳（わけ）ありません | You have my apologies. |
| よろしかったら | if it is okay (polite) |
