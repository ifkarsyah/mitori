# U-verbs

| Japanese | Meaning |
|---|---|
| 開（あ）く | (something) opens（〜が） |
| 謝（あやま）る | to apologize（person に） |
| 押（お）す | to press; to push（〜を） |
| 落（お）とす | to drop (something)（〜を） |
| お湯（ゆ）が沸（わ）く | water boils |
| 転（ころ）ぶ | to fall down |
| 壊（こわ）す | to break (something)（〜を） |
| 咲（さ）く | to bloom（〜が） |
| 閉（し）まる | (something) closes（〜が） |
| 助（たす）かる | to be saved; to be helped（〜が） |
| 頼（たの）む | to ask (a favor)（person に〜を） |
| つく | (something) turns on（〜が） |
| 汚（よご）す | to make dirty（〜を） |

This lesson's transitivity pairs ([[../grammar/transitivity-pairs]]) run through this whole list — each has an intransitive counterpart in [[ru-verbs]].
