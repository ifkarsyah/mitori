# 〜と (whenever A, B)

Present-tense **short form** ＋ と means *whenever* the situation described by the predicate holds, another thing happens. Distinct from the noun-connecting と covered in [[../../../genki-1/4-the-first-date/grammar/と]] — this と follows a full clause, not a bare noun.

私（わたし）はその人（ひと）と話（はな）すと元気（げんき）になる。
Whenever I talk with that person, I feel uplifted.

道（みち）が込（こ）んでいると時間（じかん）がかかる。
Whenever the streets are crowded, it takes longer to get there.

clause A（short, present）と　clause B。　＝　"Whenever A happens, B happens too."

## Cause-effect for a specific event
メアリーさんが国（くに）に帰（かえ）ると さびしくなります。
If Mary goes back home, we will be sad and lonely.

## Tense: A is always present; B can be either
私は子供（こども）の時、冬（ふゆ）になるとかぜをひきました。
When I was young, whenever winter arrived, I caught a cold.

The event in clause B must **follow** the event in clause A — so a と sentence can't reverse that order:
×私はその人と話すと喫茶店（きっさてん）に行きます。("Whenever I talk with that person, we go to a coffee shop" — wrong if talking and going aren't in that causal order)

## With adjective ideas in B — usually expressed as a change
Following the い-adjective base ＋ くなる and な-adjective base ＋ になる pattern from [[../../../genki-1/10-winter-vacation-plans/grammar/adjective-なる]]:

秋（あき）になると木（き）が赤（あか）くなります。
Whenever fall arrives, trees turn red.

夜（よる）になると町（まち）が静（しず）かになります。
Whenever night comes, the town becomes quiet.
