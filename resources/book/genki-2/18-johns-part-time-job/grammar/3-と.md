# 〜と (whenever A, B)

Present-tense **short form** ＋ と means *whenever* the situation described by the predicate holds, another thing happens. Distinct from the noun-connecting と covered in [[../../../genki-1/4-the-first-date/grammar/8-と]] — this と follows a full clause, not a bare noun.

<ruby>私<rt>わたし</rt></ruby>はその<ruby>人<rt>ひと</rt></ruby>と<ruby>話<rt>はな</rt></ruby>すと<ruby>元気<rt>げんき</rt></ruby>になる。
Whenever I talk with that person, I feel uplifted.

<ruby>道<rt>みち</rt></ruby>が<ruby>込<rt>こ</rt></ruby>んでいると<ruby>時間<rt>じかん</rt></ruby>がかかる。
Whenever the streets are crowded, it takes longer to get there.

clause A（short, present）と　clause B。　＝　"Whenever A happens, B happens too."

## Cause-effect for a specific event
メアリーさんが<ruby>国<rt>くに</rt></ruby>に<ruby>帰<rt>かえ</rt></ruby>ると さびしくなります。
If Mary goes back home, we will be sad and lonely.

## Tense: A is always present; B can be either
私は<ruby>子供<rt>こども</rt></ruby>の時、<ruby>冬<rt>ふゆ</rt></ruby>になるとかぜをひきました。
When I was young, whenever winter arrived, I caught a cold.

The event in clause B must **follow** the event in clause A — so a と sentence can't reverse that order:
×私はその人と話すと<ruby>喫茶店<rt>きっさてん</rt></ruby>に行きます。("Whenever I talk with that person, we go to a coffee shop" — wrong if talking and going aren't in that causal order)

## With adjective ideas in B — usually expressed as a change
Following the い-adjective base ＋ くなる and な-adjective base ＋ になる pattern from [[../../../genki-1/10-winter-vacation-plans/grammar/5-adjective-なる]]:

<ruby>秋<rt>あき</rt></ruby>になると<ruby>木<rt>き</rt></ruby>が<ruby>赤<rt>あか</rt></ruby>くなります。
Whenever fall arrives, trees turn red.

<ruby>夜<rt>よる</rt></ruby>になると<ruby>町<rt>まち</rt></ruby>が<ruby>静<rt>しず</rt></ruby>かになります。
Whenever night comes, the town becomes quiet.
