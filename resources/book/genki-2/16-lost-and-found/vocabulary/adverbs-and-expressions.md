# Adverbs & Expressions

|---|---|

| この間（あいだ） | the other day |
| このぐらい | about this much (＝これぐらい／このくらい／これくらい) |

| これから | from now on |
| 失礼（しつれい）します | Excuse me.; Sorry to interrupt you. |
| 自分（じぶん）で | (do something) by oneself |
