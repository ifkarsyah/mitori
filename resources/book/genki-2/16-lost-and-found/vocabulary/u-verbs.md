# U-verbs

| Japanese | Meaning |
|---|---|
| 起（お）こす | to wake (someone) up（〜を） |
| おごる | to treat (someone) to a meal（person に meal を） — see [[../phrases/おごる-ごちそうする]] |
| 落（お）ち込（こ）む | to get depressed |
| 困（こま）る | to have difficulty |
| 出（だ）す | to take (something) out; to hand in (something)（〜を） |
| 連（つ）れていく | to take (someone) to (a place)（person を place に） |
| 直（なお）す | to correct; to fix（〜を） |
| 道（みち）に迷（まよ）う | to become lost; to lose one's way |
| 見（み）つかる | to be found（〜が） |
| 迎（むか）えに行（い）く | to go to pick up（place まで／に person を） |
| 訳（やく）す | to translate（source を target に） |
| 笑（わら）う | to laugh |
