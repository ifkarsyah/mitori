# Irregular Verbs

| Japanese | Meaning |
|---|---|
| 〜かおをする | to look... (facial expression)（〜な／〜そうな） |
| がっかりする | to be disappointed（〜に） |
| 我慢（がまん）する | to be tolerant/patient（〜を） |
| 世話（せわ）をする | to take care of...（〜の） |
| 同情（どうじょう）する | to sympathize（〜に） |
| パンクする | (tire) goes flat（〜が） |
| 戻（もど）ってくる | (something/someone) comes back |
| 優勝（ゆうしょう）する | to win a championship |
