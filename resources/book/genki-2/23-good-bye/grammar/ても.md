# 〜ても

"A ても B" means "B, even if A" — B is true regardless of A, so certainly true if A doesn't hold. Contrast with たら's straightforward if-then meaning.

雨（あめ）が降（ふ）っても、ピクニックに行（い）きます。
I will go on a picnic even if it rains.
（cf. 雨が降ったら、ピクニックに行きません。"I will not go on a picnic if it rains.")

暑（あつ）くても、エアコンをつけません。
I will not turn on the air conditioner, even if it is hot.
（cf. 暑かったら、エアコンをつけます。"I will turn on the air conditioner, if it is hot.")

子供（こども）でも、わかります。
Even a child will get it.
（cf. 子供だったら、わかりません。"If you are a child, you will not get it.")

## Formation
Add も to the verb or い-adjective **te-form**. な-adjectives and nouns use でも. Note that verb たら and ても forms look similar, but adjective たら and ても forms look quite different.

| | ても | (compare たら) |
|---|---|---|
| verbs | 買（か）う → 買っても | 買ったら |
| い-adjectives | 悲（かな）しい → 悲しくても（×悲しかっても） | 悲しかったら |
| な-adjectives | 元気（げんき）（な） → 元気でも（×元気だっても） | 元気だったら |
| nouns | 学生（がくせい） → 学生でも（×学生だっても） | 学生だったら |

## Negative ても — based on short-form negative
| | ても | (compare たら) |
|---|---|---|
| verbs | 買わない → 買わなくても | 買わなかったら |
| い-adjectives | 悲しくない → 悲しくなくても | 悲しくなかったら |
| な-adjectives | 元気じゃない → 元気じゃなくても | 元気じゃなかったら |
| nouns | 学生じゃない → 学生じゃなくても | 学生じゃなかったら |

## No inherent tense — can be followed by present or past
私（わたし）は、雨が降っていても、毎日（まいにち）、授業（じゅぎょう）に行きました。
I went to class every day, even if it rained.

日本語（にほんご）の授業が難（むずか）しくても、取（と）ったでしょう。
I would have taken the Japanese class, even if it could have been difficult.
