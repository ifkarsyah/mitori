# 〜方（かた）

The noun-forming suffix 方 follows a verb **stem** and means "the way in which the action is performed" or "how to do..."

泳（およ）ぐ → 泳ぎ方　how to swim
考（かんが）える → 考え方　the way people think

Nouns marked with other particles when paired with the verb take の before 〜方:

漢字（かんじ）を読（よ）む → 漢字の読み方　how to read the kanji; pronunciation
はしを使（つか）う → はしの使い方　how to use chopsticks
空港（くうこう）に行く → 空港の行き方　how to go to the airport (also: 空港への行き方, since に can combine with への for a goal-of-movement)
お風呂（ふろ）に入（はい）る → お風呂の入り方　how to take a bath

## With する compound verbs
日本語（にほんご）を勉強（べんきょう）する → 日本語の勉強のし方
ホテルを予約（よやく）する → ホテルの予約のし方

## 〜方 is a noun — takes は／を like any noun
たけしさんのスパゲッティの食（た）べ方はおもしろいです。
The way in which Takeshi eats spaghetti is interesting.

すみません。この漢字の書（か）き方を教（おし）えていただけませんか。
Excuse me, can you tell me how to write this kanji?
