# Volitional Form

A less formal, casual equivalent of ましょう — suggesting a plan to a close friend, for example.

## Formation
| Type | Rule | Example |
|---|---|---|
| ru-verbs | drop る, add よう | 食（た）べる → 食べよう |
| u-verbs | drop final -u, add -おう | 行（い）く → 行こう、話（はな）す → 話そう、買（か）う → 買おう、待（ま）つ → 待とう、泳（およ）ぐ → 泳ごう、読（よ）む → 読もう、死（し）ぬ → 死のう、遊（あそ）ぶ → 遊ぼう、取（と）る → 取ろう |
| irregular | | くる → こよう、する → しよう |

あしたは授業（じゅぎょう）がないから、今晩（こんばん）、どこかに食べに行（い）こう。
We don't have any classes tomorrow. Let's go some place for dinner tonight.

結婚（けっこん）しようよ。
Hey, let's get married!

## Volitional ＋ か — offering, asking for an opinion
手伝（てつだ）おうか。
Shall I lend you a hand?

友（とも）だちがおもしろいと言（い）っていたから、この映画（えいが）を見（み）ようか。
Shall we see this film? My friends say it is good.

今度（こんど）、いつ会（あ）おうか。
When shall we meet again?
